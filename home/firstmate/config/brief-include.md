## Superpowers

Use the superpowers skills for this task where they apply:

- `superpowers:test-driven-development` for any feature or bug fix.
- `superpowers:systematic-debugging` for any bug, test failure, or unexpected behavior.
- `superpowers:verification-before-completion` before claiming the work is complete.
- `superpowers:requesting-code-review` before declaring a code change ready; dispatch every review subagent with model `opus`.

Do not run `superpowers:using-git-worktrees` or `superpowers:finishing-a-development-branch`: you already work in an isolated copy, and your delivery steps are defined above.
Do not run `superpowers:brainstorming`'s interactive question loop; route any question through the status channel defined above.
